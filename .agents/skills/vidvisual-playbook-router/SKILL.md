# Vid-Visual Playbook Router

## Goal
Make every task follow one disciplined loop and pull in the right specialist skills, so the work is consistent instead of ad hoc.

## The loop (always)
1. Understand: restate the task in 2 lines. List the files and docs you must read first. Read them.
2. Plan: at most 8 bullets, naming the files you will touch and how you will verify. If the task touches more than 3 files, or anything about money, auth, user data, or deletion, show the plan and wait for my OK. Otherwise continue.
3. Build: the smallest change that solves the problem.
4. Verify: apply the verify-before-done skill.
5. Report: use the report format below.

## Routing table
- New feature: founder-ceo-operator (is it worth building), ux-flow-architect, ui-design-director, nextjs-vercel-specialist, backend-database-auth, qa-testing-release, analytics-metrics-analyst.
- Landing page or marketing page: positioning-and-messaging, conversion-copywriter, seo-content-engine, ui-design-director, performance-web-vitals, accessibility-wcag-guardian.
- Pricing, plans, limits, credits: pricing-and-packaging, growth-activation-plg, payments-billing-engineer.
- Anything touching login, user data, uploads, payments, API keys, or AI prompts: security-privacy-guardian, always.
- AI generation or export features: ai-generation-pipeline, video-gif-export-pipeline.
- Slow pages or heavy bundles: performance-web-vitals.
- Launch, X posts, Product Hunt, changelog: build-in-public-launch, brand-identity-director.
- Deciding what to do next: founder-ceo-operator, customer-discovery-mom-test, growth-activation-plg, analytics-metrics-analyst.
- Code structure, refactor, tech debt: staff-engineer-architecture.

## Conflict rules
- Security and data safety beat speed.
- Clarity for the user beats cleverness.
- Revenue and growth claims need evidence or must be labelled as hypotheses.
- If a skill and my direct instruction disagree, follow my instruction and tell me the tradeoff in one line.

## Behaviour rules
- Ask me at most 3 questions, and only when truly blocked. Otherwise pick a sensible default, say what you chose, and continue.
- Never change pricing, plan limits, auth rules, or delete data without my explicit approval.
- Name the skills you applied in your report.

## Report format (max 10 lines)
Changed / Verified (command and result) / Risks / Skills applied / Next best step.
