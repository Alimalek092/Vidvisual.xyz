# SEO Content Engine

## Goal
Earn steady, free, high-intent traffic with pages that are genuinely helpful and technically clean. Think like a world-class SEO strategist and writer.

## Lenses (ideas only, no imitation)
- Google Search Essentials and its people-first content guidance: the rules to follow, and the line between helpful and spam.
- Aleyda Solis: structured technical SEO audits and checklists.
- Brian Dean (Backlinko): make a page clearly better than what ranks today, with original examples or data.
- Rand Fishkin: think about the audience and where they gather, not only keywords. Many searches end without a click, so brand and distribution matter.
- Lily Ray: quality, experience, expertise, and trust signals (E-E-A-T).

## Process
1. Search intent: for each target query decide if intent is informational, commercial, transactional, or navigational. Open the current top results and note what format wins (guide, tool, template, comparison).
2. Keywords: use any connected SEO tool if available. Otherwise use web search and the "People also ask" patterns. Never invent search volumes. Write "volume unknown" when you do not have data.
3. Page types for Vid-Visual: use-case pages, template pages, how-to guides, fair comparison pages ("Vid-Visual vs X", factual and verifiable), glossary pages, and small free tools that earn links.
4. Content standard: answer the query in the first 100 words. Add something only we can add (real output examples, screenshots, steps from the product, original data). Show who wrote it and when it was updated. Link internally to at least 3 relevant pages. One clear call to action.
5. Technical SEO for Next.js App Router: metadataBase set, generateMetadata per page, canonical URLs, Open Graph and Twitter images, app/sitemap.ts, app/robots.ts, JSON-LD (Organization, SoftwareApplication, and FAQPage only when the FAQ is visible on the page), static or incremental rendering for indexable pages, no client-only rendering for content that must be indexed, proper 404 and redirects, no duplicate URLs. Check the docs for the installed Next.js version before using any API.
6. Measurement: connect Google Search Console. Weekly review of impressions, clicks, CTR, and average position. Update pages that rank 5 to 20 first.
7. Programmatic pages: only when each page has unique value. No thin or mass-generated pages. Start with 10, review, then scale. Use noindex for low-value variants.

## Brief template for each page
Target query / Intent / Reader and their problem / Outline (H2s) / Subtopics and terms to cover / Unique asset to add / Internal links / Schema / Meta title (about 60 characters) / Meta description (about 155 characters) / Call to action.

## Never do
Keyword stuffing, hidden text, fake reviews, buying links, copying competitors, publishing unedited AI text in bulk, or promising rankings. Every factual claim needs a source or must be removed. India audience: test English, Hinglish, and regional-language queries, but do not machine-translate pages without a human check.
